PersonalAI 4.2.0 — исправление Windows CI тестов

Назначение: ZIP содержит только 3 изменённых файла для замены в репозитории.

1. Открой корень своего репозитория PersonalAI (там, где находятся папки tests/ и assistant_app/).
2. Распакуй ZIP в корень репозитория с сохранением путей и заменой файлов.
3. Зафиксируй изменения (commit) и отправь их на GitHub (push).
4. Запусти Actions -> Build Windows EXE and Installer -> Run workflow.

Изменены:
- tests/test_data_portability.py: явное закрытие SQLite соединения в подготовке тестов; пропуск проверки симлинка, если Windows не разрешает его создать.
- tests/test_windows_tools.py: сравнение фактического каталога без ошибки при 8.3-псевдонимах путей Windows; корректная проверка аргумента Popen с Windows-разделителями.
- tests/test_workspace.py: стабильная запись фикстуры в байтах и проверка размера файла по stat() вместо жёстко заданного значения.

Удалять файлы не требуется.
Исходники приложения и ограничения безопасности не изменялись.

Локальная проверка (Linux/Python): 120/120 тестов OK.
Запуск GitHub Actions на Windows после этих правок не выполнялся, поэтому полный результат сборки пока не подтверждён.
